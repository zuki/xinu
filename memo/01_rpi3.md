# Raspberry Pi 3 B+版Xinuについて

## メモリレイアウト

```
1GBのRAM (物理メモリ) が利用できる. 1GB == 0x3FFFFFFF

   +----------+
   |          |
   | Local Per| -> 0x40000000 - 0x4003FFFF ローカルペリフェラル用に予約
   |          |
   +----------+
   |          |
   | IO SPACE | -> 0x3F000000 - 0x3FFFFFFF IO用に予約 (GPIO, UART, SYS TIMER, USB CORE)
   |          |
   +----------+
   |          |
   |          |
   |   HEAP   | -> getmem はここから割り当てる
   |          |
   |          |
   +----------+ <- memheap
   | OS STACK | -> null プロセスのスタックになる
   +----------+
   |   BSS    | -> C 環境で必要
   +----------+
   |   TEXT   | -> XINUのコード
   |          |
   +----------+ <- 0x8000
   | RESERVED | -> 割り込みハンドラとベクタ
   +----------+ <- 0x0000
```

## 起動シーケンス

```
_start : loader/platforms/arm-rpi3/start.S
    nulluser() : system/initialize.c
        platorminit() : system/platform/arm-rpi3/platforminit.c
            set platform
            bcm2837_power_init()
            mmu_init()
            mutext[]の初期化
            dma_buf_init()
            random_init()
            quetab_mutex, thrtab_mutex[], semtab_mutex[]の初期化
        sysinit() : system/initialize.c
            thrtab[]の初期化
            NULLスレッド(0-3)の作成
            sentab[], montab[], bfptab[], readylist[]の初期化
            clkinit()
            mailboxinit()
            devtab[]の初期化
            usbinit() : device/usb/usbcore.c
                usb_bus_lockの作成
                usb_register_device_driver(&usb_hub_driver) : USBハブドラ場の登録
                hcd_start() : USbホストコントローラの起動
                usb_attach_device(usb_root_hub) : ルートハブの接続
            netInit() : network/net/netInit.c
                netiftab[]のクリア
                netpoolの割当
                arpInit()
                rtInit() : ルートテーブルの初期化
                icmpInit()
                ready(create(tcpTimer)) : TCPの初期化（tcptimerプロセスの開始）
        unparkcore(1-3) : system/platforms/arm-rpi3//unparkcore.c
        enable() : system/platforms/arm-rpi3//intutils.S
        ready(create(main)) : system/main.c
            すべてのEnternetデバイスをopen
            CONSOLEをopenしてshellにつなぐ
            shellを開始
```

## USBホストコントローラの処理シーケンス

```
hcd_start()
    dma_buf_alloc()
    dwc_poer_on()                   : DWCの電源オン
    dwc_soft_reset()
    dwc_setup_dma_mode()            : 3種FIFOサイズを設定してDMAオン
    dwc_setup_interrupts()          : DWCコアレベルの割り込みオン
    dwc_start_xfer_scheduler()      : xfer要求スケジューラスレッドの実行

hcd_submit_xfer_request()
    mailboxSend(hcd_xfer_mailbox, req)  : xfer要求キューにreqを入れる

dwc_schedule_xfer_requests()        : USB転送要求スケジューラスレッド
    while
        req = mailboxReceive()      : xfer要求キューから要求を取得
        is_root_hub()
            dwc_process_root_hub_request(req)
        else
            chan = dwc_get_free_channel()       : チャネルの取得
            dwc_channel_start_xfer(chan, req)   : xfer開始(レジスタ設定)
                dwc_channel_start_transaction(chan, req) : チャネルの割り込みをオン
            dwc_handle_channel_halted_interrupt(chan) : チャネル割り込み処理
                dwc_handle_normal_channel_halted : xfer成功時の後処理と次の処理の指定
                if 再転送、次の転送が必要
                    dwc_channel_start_xfer()        : xfer全体をリスタート
                    dwc_channel_start_transaction() : 次のトランザクションをスタート
                else 転送完了、エラー発生、遅延再スタートが必要
                    if 遅延再スタートが必要
                        defer_xfer(req)
                    usb_complete_xfer(req)           :
                        req->completion_cb_func(req)

hcd_stop
    disble_irq(IRQ_USB)             : USB割り込みラインとハンドラを無効
    kill(dwc_xfer_scheduler_tid)    : xfer要求スケジューラスレッドの停止
    mailboxFree(hcd_xfer_mailbox)   : xfer要求キューの解放
    semfree(chfree_sema)            : 空きチャネル管理セマフォの解放
    dwc_poer_off()                  : DWCの電源オフ
```
